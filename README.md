# 轻量文件页数统计助手

仿"奈末/PageAID 批量页数统计精灵"的轻量版。把文件 / 文件夹直接**拖进窗口**，
不打开文档，秒出单文件页数 + 总页数，自带打印计价、满减发货测算，
并可导出 Excel / CSV 表格。

## 下载使用

- 直接双击 `dist\页数统计助手.exe` 即可运行，**无需安装 Python 和任何依赖**
- **系统要求：Windows 10 / 11（64 位）**
- ❌ **Windows 7 无法使用**（新版 Python 运行时已不支持 Win7）
- Windows 8.1 理论可用但未测试，建议使用 Win10 及以上系统

## 功能一览

### 1. 页数统计
- 拖入文件或整个文件夹（可勾选是否包含子文件夹），自动批量统计
- 支持"从剪贴板导入"：资源管理器中复制文件后一键导入
- 支持格式：**pdf / doc / docx / docm / xls / xlsx / xlsm / ppt / pptx / pptm**
- 统计原理：
  - PDF：解析 PDF 页对象（pypdf）
  - docx/xlsx/pptx：读取文档属性中的页数（docProps/app.xml）
  - doc/xls/ppt：读取 OLE 摘要信息中的"页数"
  - 个别文件没存页数属性时，**自动调用本机 Office / WPS 后台补算真实页数**（不弹窗口）
- 自动忽略 Word/PPT 打开时产生的 `~$` 临时锁文件
- 状态列实时显示：待处理 / 处理中 / 完成 / 无页数数据 / 无法读取
- 统计中新拖入的文件自动排队接续处理

### 2. 打印计价（自动联动）
- **附加费(元)**：额外费用，计入两个总价
- **总页**：所有文件页数之和
- **双面总页(张)**：总页 ÷ 2 向上取整（双面打印用纸量）
- **单价(元)**：每页/每张单价
- **单面总价** = 总页 × 单价 + 附加费
- **双面总价** = 双面总页 × 单价 + 附加费

### 3. 满减 / 发货测算
- **满减**：填 `10-5` 表示满 10 减 5；不填则不参与
- **满多少发货(元)**：店铺起送/发货门槛（按满减后的实付金额判断）
- **计价方式**：双面（默认）/ 单面 下拉切换
- **还能加打**：两行结果，直接告诉你
  - 还能打印多少张（双面）/ 多少页（单面）
  - 折合多少**面**（1 张双面纸 = 2 面）
  - 已达标时显示"已满足发货条件"

### 4. 导出表格
- 一键导出 **Excel(.xlsx)**（带表头样式、汇总与计价信息）或 **CSV**
- 导出内容：文件路径、文件名、类型、状态、页数，以及总页、双面总页、
  附加费、单价、单面/双面总价、满减、还能加打等汇总行

## 运行方式

### 方式一：exe（推荐）
双击 `dist\页数统计助手.exe`。

### 方式二：源码运行
```powershell
pip install pypdf olefile tkinterdnd2 openpyxl pywin32
python app.py
```

> 依赖均为可选增强项：缺 tkinterdnd2 只能用按钮添加文件；缺 pypdf 时 PDF 用内置
> 正则粗略统计；缺 olefile 时老格式 doc/xls/ppt 读不到页数属性；缺 openpyxl 时
> 导出自动降级为 CSV；缺 pywin32 时无法用 Office/WPS 补算缺失页数。

## 常见问题

- **拖拽没反应？** 请勿用"以管理员身份运行"；普通权限下拖拽正常。
  也可以用"从剪贴板导入"（资源管理器选中文件 Ctrl+C → 点按钮）。
- **显示"无页数数据"？** 该文件内部没存页数属性，程序会自动调 WPS/Office 补算；
  若显示"无法读取"则文件损坏或被占用。
- **docx 页数和 Word 里看到的不一致？** 页数取自文件保存时写入的属性，
  修改后未保存的改动不计入；也可用 WPS 补算方式重新统计。
